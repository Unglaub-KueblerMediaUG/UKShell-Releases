# UKShell – Downloads

SSH-Client für macOS und Windows.

Die aktuelle Version gibt es unter [Releases](../../releases/latest):

- **macOS Apple Silicon (M1 und neuer):** `UKShell_<Version>_aarch64.dmg`
- **macOS Intel:** `UKShell_<Version>_x64.dmg`
- **Windows 10/11:** `UKShell_<Version>_x64.msi`

Installierte Versionen aktualisieren sich selbst (Einstellungen → Updates).

Die Installer sind derzeit nicht signiert. Beim ersten Start:
- **macOS:** Rechtsklick auf UKShell → „Öffnen“ → „Öffnen“, oder Systemeinstellungen → Datenschutz & Sicherheit → „Trotzdem öffnen“.
- **Windows:** Bei „Der Computer wurde durch Windows geschützt“ auf „Weitere Informationen“ → „Trotzdem ausführen“.

Dieses Repository enthält nur die fertigen Installer, keinen Quellcode.
